 GoCabs: A Web3-Powered Event Shuttle Platform
 GoCabs is a next-generation, event-focused shuttle booking application built with React Native and
 Expo. It addresses the friction of event transportation by building a community-owned ecosystem. It
 leverages the Solana blockchain to offer a seamless booking experience, using USDC for payments
 and NFTs for access control, rewards, and fractional ownership.
 This project provides a complete transportation ecosystem, splitting functionality into two core
 applications:
 1. Seeker App (Rider): The customer-facing app for finding events, booking shuttles, and managing
 Web3 assets.
 2. Fleet Management App (Driver/Owner): The operational backend for drivers to manage rides
 and for owners to manage their fleet.
 1. Core Concept: NFT-Based Partial Gating
 The app operates on a "partial gating" model, creating a clear conversion funnel for users to become
 platform stakeholders. This model is designed to drive NFT adoption by demonstrating value upfront.
 Non-NFT Holders (Teaser Mode): Can download the app, browse events, and see shuttle
 availability. All booking, reward, and staking features are disabled. Key information like pricing is
 blurred, and calls-to-action prompt the user to acquire an NFT to unlock the full experience.
 NFT Holders (Full Access): Unlock the app's full utility. They can book rides, track shuttles in
 real-time, earn rewards, and participate in the staking and governance ecosystem.

 Views details like departure/arrival times and price (in USDC).

 2.3. NFT Holder Benefits
 Exclusive Access: Only NFT holders can book rides, ensuring a premium, less-crowded service.
 Priority Service: Get priority access to shuttle services, reduced wait times, and guaranteed
 seats.
 Points & Rewards: Earn XP for every ride taken, which can be redeemed for USDC.
 Revenue Share (Staking): Stake NFTs to earn a share of platform revenue, distributed monthly in
 USDC.
 Tier 1: Stake 1 NFT to earn a 25% share of the revenue pool.
 Tier 2: Stake 3+ NFTs to earn a 40% share of the revenue pool.
 Fractional Ownership: Link staked NFTs to specific shuttles to earn a pro-rata share of that
 individual shuttle's monthly revenue (paid in USDC).
 Governance: Participate in on-chain voting to influence platform development, new routes, and
 expansion.

 4. Technology & Architecture
 This project is built on a modern, Web3-native stack. The React Native app communicates via a
 GraphQL API to a Node.js backend. The backend handles business logic and integrates with Helius
 for NFT verification and Solana Pay for payments. PostgreSQL stores core data, while Redis caches
 on-chain data like NFT ownership to ensure a fast user experience.
